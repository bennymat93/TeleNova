TeleNova V3.0

NovaTV Kodi build with the built-in TeleScope AI Telegram engine. Hebrew / English / Russian.

Kodi: Settings → File manager → Add source → https://bennymat93.github.io/TeleNova/ → Add-ons → Install from zip file.

What's in V3.0

  • NovaTV 3.0.0: one catalogue for movies and series, search across every source, IPTV, radio, AI Hebrew subtitles.
  • TeleScope AI 3.0.0: the Telegram engine. Its settings and login are its own; NovaTV's "Search all sources", Movies → Search, Series → Search and every movie / episode also use it.
  • Fixed: Telegram login failed on first run with "No compatible wheel for pyaes".
  • Wizard 3.0.0: an update keeps add-ons installed from the repository.

Windows

TeleNova-Setup.cmd – download and double-click: installs Kodi 21 if it is missing, the build and NovaTV 3.0.0. Previous Kodi data is kept as a backup folder.

iOS

Kodi 20.5 IPA

BN Stream Web (browser)

BN Stream Web – phone, tablet, computer and TV browsers; can be installed as an app (Add to Home screen).
