# BN Stream (TeleNova) - אפליקציית Android

קובץ אחד לכל המכשירים: **[TeleNova.apk](https://bennymat93.github.io/TeleNova/apk/TeleNova.apk)** - טלפונים, טאבלטים,
Android TV / סטרימרים ומערכות Android לרכב. Android 7 ומעלה. גרסה ופרטים: [version.json](version.json).

האפליקציה היא גרסת הדפדפן של BN Stream בתוך מעטפת מקומית: אותן פונקציות כמו באתר, ובנוסף ניהול קבצים, מקש "חזור",
שלט, מסך מלא וקישורים. הרשאה אחת בלבד: אינטרנט.

## התקנה
1. במכשיר: פתחו בדפדפן את `https://bennymat93.github.io/TeleNova/apk/TeleNova.apk` והורידו.
2. פתחו את הקובץ; אשרו "התקנה ממקור לא ידוע" לדפדפן / למנהל הקבצים כשהמערכת מבקשת.
3. Android TV / סטרימר: עם אפליקציית Downloader (הקלידו את הכתובת), או מהמחשב: `adb install -r TeleNova.apk`.
4. עדכון: מתקינים את הקובץ החדש מעל הקיים (הנתונים וההתחברויות נשמרים). תוכן האתר מתעדכן לבד גם בלי APK חדש:
   כשבאתר יש גרסת ווב חדשה יותר מזו שבתוך ה-APK, האפליקציה מציגה את האתר.

## שימוש
- **חזור** - חזרה בתוך האפליקציה; בדף הבית לחיצה שנייה יוצאת.
- **תפריט האפליקציה** - לחיצה ארוכה על "חזור" או מקש התפריט בשלט: קבצים, טעינה מחדש, מקור התוכן, אודות, יציאה.
- **קבצים** - גיבויים, הגדרות מיוצאות, כתוביות, רשימות ערוצים והורדות נשמרים בתיקיות בתוך האפליקציה. מסך "קבצים"
  (כפתור "קבצים באפליקציה" בדפי הגיבוי / ההגדרות, או מתפריט האפליקציה): ייבוא מהמכשיר, ייצוא למכשיר, שיתוף, העברה,
  שינוי שם, מחיקה. כשדף מבקש קובץ (שחזור גיבוי, כתוביות, רשימת ערוצים) בוחרים "תיקיית האפליקציה" או "המכשיר".
- **קישורים** - קישור הצימוד של ה-build (`.../web/#pair=...`), קישורי t.me ו"שיתוף" של קישור מאפליקציה אחרת נפתחים באפליקציה.
