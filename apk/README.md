# BN Stream (TeleNova) - אפליקציית Android

קובץ אחד לכל המכשירים: **[TeleNova.apk](https://bennymat93.github.io/TeleNova/apk/TeleNova.apk)** - טלפונים, טאבלטים,
Android TV / סטרימרים ומערכות Android לרכב. Android 7 ומעלה. גרסה ופרטים: [version.json](version.json).

האפליקציה היא גרסת הדפדפן של BN Stream בתוך מעטפת מקומית: אותן פונקציות כמו באתר, ובנוסף ניהול קבצים, מקש "חזור",
שלט, מסך מלא וקישורים. הרשאה אחת בלבד: אינטרנט.

## התקנה
1. במכשיר: פתחו בדפדפן את `https://bennymat93.github.io/TeleNova/apk/TeleNova.apk` והורידו.
2. פתחו את הקובץ; אשרו "התקנה ממקור לא ידוע" לדפדפן / למנהל הקבצים כשהמערכת מבקשת.
3. Android TV / סטרימר: עם אפליקציית Downloader (הקלידו את הכתובת), או מהמחשב: `adb install -r TeleNova.apk`.
4. עדכון: האפליקציה מציגה את האתר החי, ולכן כל עדכון של גרסת הווב מופיע אחרי רענון - בלי APK חדש. העותק שבתוך
   ה-APK משמש רק כשאין חיבור לאתר. APK חדש (נדיר) מתקינים מעל הקיים; הנתונים וההתחברויות נשמרים.

## חדש ב-1.1.0
- **מנוע העזר (Worker) מובנה באפליקציה:** Real-Debrid, StremThru, Ktuvit, מדריך השידורים של epgshare01 ו-YouTube
  עובדים בלי להקים או להקליד שום דבר. הכתובת זהה לזו של אפליקציית iOS, כך שגיבוי עובר בין השתיים.
- **התחברות לטלגרם:** תוקנה התקלה שעצרה את ההתחברות בשלב האחרון (חסר בגרסת הווב 5.1.0); בשלב קוד ה-QR מופיע
  כפתור "אישור באפליקציית טלגרם במכשיר הזה".
- תפריט ומסך הקבצים גם ברוסית. שם האפליקציה על המסך: BN Stream (מזהה החבילה ושם קובץ ההורדה לא השתנו).

## שימוש
- **חזור** - חזרה בתוך האפליקציה; בדף הבית לחיצה שנייה יוצאת.
- **תפריט האפליקציה** - לחיצה ארוכה על "חזור", מקש התפריט בשלט, או הכפתור "קבצים ורענון" בדפי הגיבוי / ההגדרות:
  קבצים, רענון (הגרסה החדשה מהאתר), מקור התוכן, אודות, יציאה. לחיצה ארוכה על סמל האפליקציה: קיצורי "קבצים" ו"רענון".
- **קבצים** - גיבויים, הגדרות מיוצאות, כתוביות, רשימות ערוצים והורדות נשמרים בתיקיות בתוך האפליקציה. מסך "קבצים"
  (מתפריט האפליקציה): ייבוא מהמכשיר, ייצוא למכשיר, שיתוף, העברה,
  שינוי שם, מחיקה. כשדף מבקש קובץ (שחזור גיבוי, כתוביות, רשימת ערוצים) בוחרים "תיקיית האפליקציה" או "המכשיר".
- **קישורים** - קישור הצימוד של ה-build (`.../web/#pair=...`), קישורי t.me ו"שיתוף" של קישור מאפליקציה אחרת נפתחים באפליקציה.

## מה לא נבדק
- **חדש ב-1.1.0 ולא נבדק:** StremThru, Ktuvit, epgshare01 ו-YouTube דרך מנוע העזר; השלמת התחברות Real-Debrid;
  תיקון ההתחברות לטלגרם והכפתור "אישור בטלגרם"; ביטול בקשה באמצע וקבצי מדריך גדולים.
- ייבוא / ייצוא ברקע במסך הקבצים (חדש ב-1.0.1), וניקוי שמירות שנקטעו.
- הערה: בבדיקה מוקדמת, כשהמחשב היה בעומס מלא ואפליקציה נוספת רצה על אותו אמולטור, האפליקציה הציגה פעם אחת
  "לא מגיבה" אחרי רענון (גם ממשק המערכת לא הגיב אז). בבדיקה החוזרת הרענון עבד פעמיים בלי תקלה.
- מכשיר אמיתי כלשהו: טלפון, Android TV / סטרימר אמיתי, מערכת רכב; גרסאות Android 7-14.
- התחברות לטלגרם וניגון מטלגרם בתוך האפליקציה (דורש את ההתחברות של בעל החשבון).
- ייבוא / ייצוא דרך בורר הקבצים של המערכת ("המכשיר"), שיתוף קובץ, העברה / שינוי שם / מחיקה במסך הקבצים.
- קישור צימוד `#pair=` אמיתי, קישורי t.me ו"שיתוף" מאפליקציה אחרת.
- כפתור מסך מלא ונעילת כיוון בטלפון; רדיו ברקע לאורך זמן.

## מגבלות ידועות
- חיבור Google Drive: Google חוסמת התחברות בתוך WebView, ולכן ההתחברות נפתחת בדפדפן וחוזרת לאפליקציה רק אם
  Android מעביר אליה את הקישור (ב-Android 12+ צריך להפעיל לאפליקציה "פתיחת קישורים נתמכים"). לא נבדק; הפתרון המלא
  דורש שינוי קטן בגרסת הווב - `android/WEB_CHANGES_NEEDED.md`.
- המסך לא נשאר דולק בזמן ניגון YouTube (נגן מוטמע מאתר אחר).
- קבצים גדולים מטלגרם נשמרים רק במסלול "קובץ קטן" של הדף (אותו מסמך).
- במכשירי Android TV שאין בהם בורר קבצים של המערכת, ייבוא / ייצוא "מהמכשיר" אינו זמין; תיקיית האפליקציה עובדת.
- Android Auto / Android Automotive (ממשק הרכב של גוגל) לא נתמך; מערכות רכב שמריצות Android רגיל - כן.
- טלוויזיה חיה: מנוע העזר המובנה משרת רק את השירותים שברשימה שלו, לא ערוצי http / ערוצים בלי CORS (כמו Worker
  רגיל בלי הרחבה). הדף מנסה "דרך העוזר" ונכשל מיד; תיקון הניסוח בצד הווב מפורט ב-`android/WEB_CHANGES_NEEDED.md`.
- גיבוי הגדרות שנוצר באפליקציה נושא את כתובת העוזר המובנה; בדפדפן רגיל היא לא עונה עד לתיקון בצד הווב (אותו מסמך).
