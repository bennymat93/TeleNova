# TeleNova - QA matrix: area x how it is checked

Compiled 2026-11-16 from the existing records: `src/HANDOFF.md` ([HANDOFF <section>]), `README.md`
([README <version>]), `docs/PROGRESS.md` ([PROGRESS]) and the header / docstring of each script in `src/qa/`
([qa/<file>]). No test was run and Kodi was not started for this document; "last recorded result" is the newest
statement in the log or the release notes, with its version.

Reading the columns:
- **Unit test(s)** run without Kodi (stubbed Kodi modules). **Live check(s)** talk to a running Kodi over JSON-RPC
  (port 9090) and / or to the engine's own port through `tg_rpc.py`.
- "Account" = the Telegram account logged in inside the running Kodi unless another is named.
- The 4.0.7 and 4.0.8 log sections name only their own new tests; they do not say that the regression suites were
  run again. The newest explicit regression statements are 4.0.6 (partial), 4.0.5 ("all the suites") and 4.0.2
  (itemised).
