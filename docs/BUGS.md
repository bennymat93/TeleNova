Compiled 2026-11-16 from the existing records only: `src/HANDOFF.md` (cited as [HANDOFF <section>]), `README.md`
([README <version>]), `docs/PROGRESS.md` ([PROGRESS]), the research notes in `docs/` and the headers of the scripts in
`src/qa/` ([qa/<file>]). Nothing was run for this document.

- BUG-001..017 keep the id, severity and wording of the board [PROGRESS]. BUG-018 onwards are defects the log or the
  release notes describe but the board does not list; their severity is an estimate from the described effect and is
  marked "(est.)".
- "Not verified live" is written where the record says so. "Record names no check" means the sources are silent.
